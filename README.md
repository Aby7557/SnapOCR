# SnapOCR —— 微信式截图 · 标注 · OCR · 翻译

**一个 48KB 的绿色单文件 exe**，复刻微信电脑版截图体验并大幅增强：框选截图、画笔/马赛克/方框标注、离线 OCR 文字提取、多语言翻译、微信热键智能避让。零依赖、免安装、开机自启。

```
C:\Users\Administrator\AppData\Local\SnapOCR\SnapOCR.exe
```

---

## 快速上手

1. **Alt+A**（或双击托盘图标）唤起截图
2. 按住左键**拖拽框选**区域，`Esc` / 右键取消（带尺寸提示 + 放大镜取色）
3. 松开鼠标弹出**工具条**（居中于选区下方）；`Enter` 或双击 = 直接复制图像

## 工具条

`OCR` `🌐翻译` `画笔` `马赛克` `方框` `撤销` `复制` `保存` `红✕`

| 按钮 | 功能 |
|---|---|
| **OCR** | Windows 10 内置引擎**离线识别**，小字自动放大识别，结果自动进剪贴板 |
| **翻译** | OCR 后翻译（Bing，需联网），8 种目标语言；中文自动译英、其他自动译中 |
| **画笔 / 马赛克 / 方框** | 标注工具（再点一次退出编辑，笔迹只在选区内） |
| **撤销** | 撤销最后一笔（快捷键 `Ctrl+Z`） |
| **复制 / 保存** | 图像进剪贴板 / 另存 PNG · JPG · BMP |

> 标注后再 OCR / 翻译 / 复制 / 保存，得到的都是**标注后的图**；重新框选自动清空标注。
> 工具条显示模式（**图标+文字 / 仅图标 / 仅文字**）在托盘菜单切换，自动记住。

## 微信热键避让

SnapOCR 与微信都用 `Alt+A` 截图，本工具**自动避让**：

- 每 3 秒检测微信进程（新版 `Weixin.exe` / 旧版 `WeChat.exe`），毫秒级开销、无内存增长
- 微信运行中 → 自动暂停热键（托盘提示"微信运行中，热键已暂停"），**零按键冲突**
- 微信退出 → 约 3 秒内自动恢复热键，气泡提示
- 不需要此功能？托盘菜单取消勾选即可（不再有任何后台检测）

## 自检

```
SnapOCR.exe --selftest
```
写 `%TEMP%\SnapOCR_selftest.log`：OCR 语言 / 大图识别 / 小字条识别（28px）/ Bing 翻译 四项回归测试。

## 常见问题

1. **Alt+A 没反应？** 微信在运行时热键归微信（自动避让），用托盘菜单或双击图标截图；热键被其他程序占用时托盘会有气泡提示。
2. **OCR 没识别到？** 选区太小会自动放大重试；仍失败请检查系统"文字识别"语言包（设置 → 时间和语言 → 语言）。
3. **翻译失败？** 翻译需联网（Bing 直连可用）；OCR / 标注 / 复制 / 保存全部离线可用。
4. **卸载**：托盘取消"开机自动启动"，删除 `%LOCALAPPDATA%\SnapOCR\` 目录即可，无任何残留。

## 技术细节（开发者）

- 单文件 C#（WinForms），**系统自带 .NET Framework 4.8 `csc.exe` 编译**（`build.cmd` 一键构建，无需安装任何 SDK）
- WinRT 直连：`System32\WinMetadata\*.winmd` + 自研 `IAsyncOperation` 轮询等待 + PNG→`BitmapDecoder` 图像通道（绕开 GAC 旧版互操作程序集的身份冲突）
- 截图：GDI `CopyFromScreen`，DPI 感知，多显示器（虚拟屏幕全幅）
- 翻译：cn.bing.com 网页流程（token 自动刷新，无需 API Key）
- 自绘工具条：10 个运行时手绘 GDI 图标，三种显示模式，无任何图片/图标资源文件
